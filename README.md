This repo holds the entry for make.fun's "Spotlight @crisxai5" bounty: a public X post introducing @crisxai5 as a must-follow AI and crypto expert — covering AI agents, crypto insights, and Web3 innovation — with an original photo-style graphic made for the post. The graphic is a plain desk photograph — a phone showing a green crypto chart beside a cup of coffee, under one line of text: that style was chosen on purpose, because the first draft (a glowing neon AI-robot poster) was rejected as AI slop, while a quiet, realistic photo reads as honest and is what actually stops the scroll. POST.json names the post, and main.ts copies it to the output directory for the grader.

## Run it

```sh
mkdir -p out && MAKEFUN_BOT_DIR=. MAKEFUN_OUTPUT_DIR=out node main.ts
```
